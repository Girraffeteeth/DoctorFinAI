# 🩺 Doctor FinAI

**AI-Powered Financial Health Platform for SMEs**

Doctor FinAI helps small and medium enterprises diagnose their financial health using AI-driven insights, GST intelligence, and banking simulations.

---

## 🚀 Features

- 📊 Financial Scan from CSV Upload
- 🧠 AI-Generated Business Insights
- 📈 Revenue, Expenses & Profit Dashboard
- 🌍 Multi-Language Support (English, Hindi, Bengali, Tamil, Telugu)
- 🏦 Bank Sync Simulation
- 🧾 GST Compliance Summary
- 📄 Investor-Ready PDF Report Download

---

## 🏗️ Tech Stack

### Frontend
- React + Vite
- Tailwind CSS
- Framer Motion
- Recharts
- jsPDF + html2canvas

### Backend
- FastAPI
- Python
- Pandas
- OpenAI API (AI Insights Engine)
