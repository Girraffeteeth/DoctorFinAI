# 🩺 Doctor FinAI — AI Financial Health Platform for SMEs

Doctor FinAI is a full-stack, AI-powered financial diagnostics platform designed to help Small and Medium Enterprises (SMEs) understand their business health in seconds.

It transforms raw financial files into:
- Revenue & expense insights
- Profitability analysis
- Financial health scoring
- Cash flow outlook
- Credit readiness indicators
- GST and banking overview
- Investor-ready PDF reports

## 🧠 Problem Statement
SMEs often struggle to interpret financial data and make informed decisions due to lack of financial expertise and complex reporting tools.

Doctor FinAI simplifies this by acting as a **virtual financial doctor** — diagnosing business health, identifying risks, and providing actionable insights using AI.

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Framer Motion (animations)
- Recharts (data visualization)
- jsPDF + html2canvas (PDF export)
- Axios

### Backend
- FastAPI (Python)
- Pandas (financial data processing)
- OpenAI API (AI financial insights)
- Uvicorn

### Deployment
- Frontend: Vercel
- Backend: Render
- Version Control: GitHub

## 🧪 How It Works
1. Upload a CSV or Excel financial file
2. Backend processes revenue & expenses
3. AI generates financial insights
4. Frontend visualizes results in a live dashboard
5. Download a professional investor report as PDF
